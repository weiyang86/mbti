- `aij-ai` 是知识文档 Schema 与 API 的唯一 owner；`ClientWorkspace` 继续拥有认证 Workspace、成员和权限上下文，Audit 继续拥有审计写入。

- 仅增加 `workspace.knowledge.manage`、`workspace.knowledge.query` 权限目录。迁移幂等登记权限，并只向有效系统 OWNER 角色补授权，不向普通 MEMBER 授权。
- 新增认证保护的创建和分页列表 API。Workspace 从服务端认证上下文取得；请求体自报 `workspaceId` 被拒绝。创建与去敏审计同事务，列表不返回正文。
- 没有迁入业务客户/订单/诊断数据、业务 Prompt 或 Provider 密钥；当前没有检索、来源引用、拒答阈值或 AI 调用能力。

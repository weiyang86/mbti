## 地址、人工观察与限制

本卡没有运行服务，**没有实际可访问的 Web/API 地址，也没有管理员账号**。测试中出现的 `http://127.0.0.1:46111` 等只是写入合成 manifest 的配置值，不代表有监听。可在负责人新建的空目录手动运行：

1. `pnpm run aij:project -- create --project-id sample-one --environment development --dir <新目录1> --web-port <空闲端口1> --api-port <空闲端口2>`。
2. `pnpm run aij:project -- show --dir <新目录1>`，核对派生身份、端口、issuer、Cookie 前缀和 storageRoot；确认没有输出秘密。
3. 用另一 projectId/端口建立第二目录，并追加 `--peer <新目录1>/aij.project.json`；预期 `CREATED` 且身份/端口/storageRoot 不同。用重复 projectId 或端口重试，预期 exit 2 且目录不创建。
4. 不尝试登录或连接数据库：本卡生成配置默认关闭这些能力；独立服务、文件、凭据及 DB namespace 并行验证留给 AF-074。

示例地址只有在负责人随后启动服务并确认端口归属后才可访问。生成器不会清理或覆盖已有目录；人工临时目录及服务需由负责人自行管理。

## Owner 与实现设计

- 唯一认证/客户主体 owner：既有 `ClientAuthGuard` 与 `ClientAuthModule`；controller 不接受客户端自报项目、workspace、owner/uploader 字段。
- 唯一文件字节 owner：AF-045 的 `FilesModule` 导出 `LocalStorageAdapter`；本卡不复制存储实现。
- 唯一元数据 owner：既有 `PrismaService` 的 `FileAsset`。本卡不改 Schema 或 migration；仅 `STORAGE_ENABLED && CLIENT_AUTH_ENABLED` 时装配客户上传模块。
- API 接受 JPEG、PNG、WebP、PDF、UTF-8 plain text，拒绝 HTML、未知类型、签名不匹配、空文件和超过 5 MiB 的文件。UUID 对象键与规范 MIME 后缀用于存储标识；源文件名仅作为净化后的展示元数据。
- 写入顺序是先由 LocalStorageAdapter 独占写入并同步字节，再创建 FileAsset；数据库拒绝时仅移除本次 UUID 对象，向客户端返回固定去敏错误。成功响应不返回本机路径或 object key。

## 实现

- `AiModelExecutionService` 增加内部异步 `submit/status/cancel`。提交校验请求、幂等键和超时选项，从服务端获取当前项目与插件状态；能力、配置、模型能力、SecretRef 与预算检查和 durable enqueue 在同一事务内执行。调用方不能指定项目或插件 scope。
- `JobService` 复用既有 `RuntimeJob/RuntimeIdempotency`：并发相同请求返回同一任务；相同键对应不同请求返回 409；插件任务必须匹配服务端当前项目。状态投影不包含 payload、结果内容或错误详情；取消只接受 `pending/retry`，跨项目对象不可见。
- worker 将 abort signal 传入 Provider。超时失败保存在既有 RuntimeJob 受控状态并进入重试，异常内容被去敏；重试成功后只保存状态和无输出引用。模型输出、Trace、Cost 仍归 NEXT-15B，不在本卡实现。
- 增加 AF-092 acceptance DB 注册，并让离线认证 fixture 在内存中从隔离测试 JWT 派生客户测试密钥；不回显或写入真实凭据。
- 没有 Prisma Schema、migration、公开 API route、页面或权限目录变化。测试启动真实 Nest API host 并请求 `/health`，同时用编译后的服务连接隔离 PostgreSQL 执行队列路径；此卡没有可供人工浏览器登录的页面/公开模型执行端点，负责人统一验收仍待执行。

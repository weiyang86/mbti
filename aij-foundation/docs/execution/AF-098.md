## 实现

- 新增 `scripts/verification/ai-failure-recovery.test.mjs`，在随机隔离 test PostgreSQL 和真实 Nest HTTP 上验证 Provider 缺失时 503 且不入队、预算超限时 429 且无 Job/Trace、队列任务 Provider 失败后写入安全错误分类并以同一 RuntimeJob attempt 2 恢复、同一幂等键的冲突请求 409 且不覆盖既有完成任务。

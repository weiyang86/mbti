## 实现与数据 Owner

- `aij-ai` 独占 `AiKnowledgeQuestion` 问题、答案、引用、拒答/失败状态。新增 workspace+幂等键唯一约束、RuntimeJob 一对一唯一键、workspace/status 时间索引；workspace、member、runtime job 外键均为 `RESTRICT`。迁移 `20261102010000_ai_knowledge_question` 仅包含新增 enum/table/index/FK。
- `ClientWorkspace` 仍独占客户成员、Workspace 状态与 `workspace.knowledge.query` 权限校验；提交、轮询和异步执行均从服务端上下文取 Workspace，异步处理再次检查成员权限。跨 Workspace 不能读取问答记录。
- `AsyncRuntime` 仍独占任务与尝试；任务 payload 仅带 question ID，Workspace 通过已有 RuntimeJob scope 字段隔离。`SecretRef` 仍唯一解析凭据，`AiExecutionTraceService` 仍唯一拥有 Trace/Cost 事实。没有新增队列、Service owner 或成本账本。
- 新增 `POST /api/client/ai/knowledge/questions` 与 `GET /api/client/ai/knowledge/questions/:id`。重复请求按 workspace-scoped 幂等键回放；同键不同 query 返回 409。无足够证据时持久化拒答且不 enqueue/不记 Trace；有证据时先校验现有配置、能力、插件状态和 SecretRef，再入 AsyncRuntime。响应引用仅由服务端检索生成；Trace 保存形状化输入，Runtime result reference 不含答案正文；离线测试成本为 `unreported`，不伪造 provider 用量或费用。
- 离线 Provider 只在 `NODE_ENV=test`、`APP_ENV=test` 及显式 `AIJ_TEST_AI_PROVIDER_MODE=offline-knowledge` 同时成立时装配。其它环境不注册该 Provider；真实 DeepSeek 接入仍未实现/未授权。

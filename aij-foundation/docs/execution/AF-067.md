## 实现

`apps/api/src/plugin-runtime/plugin-manifest.ts` 是唯一 manifest v2 validator，沿用 AIJ API 的 `PluginRuntimeModule` 作为宿主，不建立第二份 package/service owner。Schema 校验覆盖已知字段、code/name、严格 SemVer 与支持范围、core API 兼容、依赖声明语法、权限 namespace、菜单/路由与 API path、typed config defaults/SecretRef、生命周期标识符、迁移 ID/checksum 和可选声明。manifest 的权限仅是目录元数据，不赋权给角色。错误只输出受限插件 code 和固定 issue，不输出密钥值。

`plugin-runtime.module.ts` 从静态 `Map` 注册表解析 Nest module class；不读取 manifest import 路径、不执行 hook/脚本。当前注册表有意为空：没有插件默认启动，空 enabled 列表仍为空导入；未知、重复或与静态注册不符的启用 code 在装配时被拒绝。实际安装状态、依赖图、生命周期执行/事务、恢复与管理 API 未由本卡实现。

实现契约：见 [PLUGIN_MANIFEST](../development/PLUGIN_MANIFEST.md)。来源 SDK 许可文本保留于 `apps/api/src/plugin-runtime/PLUGIN_SDK_LICENSE.txt`。源声明 All Rights Reserved；本卡不推定公开发行/再分发授权，不创建或发布 package。

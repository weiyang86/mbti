## Owner 与实现

- IntegrationCenter 是 webhook 合同和入站幂等账本唯一 owner；SecretCenter 是 SecretRef 唯一解析 owner；ProjectProfile 提供服务端项目/环境状态；Prisma/PostgreSQL 提供唯一性和事务约束。没有增加第二份 SecretCenter 或 Connector owner。
- 新增公开入站端点 `POST /api/integrations/webhooks/:projectCode/:connectorCode`。入口只接受实际登记且处于启用、已配置并具有 `webhook:receive` 的 connector。
- HMAC-SHA256 对原始请求 body 验签，签名上下文绑定版本、project、connector、时间戳和幂等键；请求时间窗为 ±300 秒，比较使用定时安全比较。格式、大小、时间窗和签名校验失败均拒绝。
- 验签密钥只通过 SecretRef 在服务端解析，不接收或记录客户端密钥；持久化记录仅含项目/connector、幂等键、原始 body SHA-256、签名时间、安装版本和接收时间，不保存原始 body、签名或密钥。
- 同项目/connector/idempotency key 加唯一约束。相同键与相同 digest 返回重复成功，不重复插入；相同键不同 digest 返回冲突。事务中再次核验 connector 状态、权限范围、SecretReference 状态和版本，撤销后的密钥不能在解析竞态后继续入账。
- 新增 `ConnectorInboundEvent` 和前向迁移 `20261101020000_connector_inbound_event`，复合外键引用 ConnectorInstallation 并使用 `RESTRICT` 删除策略。迁移只在新建的随机 AF-100 test 验收库中应用；没有触碰 dev DB、正式/共享库或旧卷。
- 无页面、无管理员权限面变化、无外部 live URL 调用。返回和运行日志不含密钥或 body。测试只发本机合成 HTTP 请求。

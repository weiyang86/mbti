## 实现

- Prisma 新增 `AiExecutionTrace`、状态/失败/成本来源枚举和 `20261101000000_ai_execution_trace` migration。每个 `(jobId, attempt)` 唯一，外键关联 RuntimeJob 与 ProjectProfile，并使用 RESTRICT 删除策略；项目归属不作为客户 Workspace/租户授权。
- AI worker 在服务端创建 Trace，关联项目、job、attempt、correlation ID、能力、Provider 与模型。Trace 输入输出只保存粗略类型/长度桶/字段数，不保存值或对象键；job 结果只留下 Trace 引用，不保存模型输出。
- Trace 使用固定失败分类，不保存 Provider 原始异常。相同 attempt 重放会核对不可变上下文；相同 Provider 完成回执幂等，冲突的回执不能覆盖已存成本。
- 成本只接受经过验证的 Provider 报价回执，以整数 nanos + 三字母币种 + `provider_reported` 保存。只有 Token 用量时保持未报价，不从 Token、日志或价格表估算。
- 详细数据与边界见 [AI_TRACE_COST](../development/AI_TRACE_COST.md)。未新增公开 Trace API、页面、权限码或真实付费 Provider 调用。

## 实现

新增五个客户租户模型：`ClientWorkspace`、`ClientWorkspaceRole`、`ClientWorkspacePermission`、`ClientWorkspaceRolePermission`、`ClientWorkspaceMembership`，并在 `MemberUser` 添加创建者和成员关系。角色、权限目录与系统管理员角色完全分开。

关键约束：Workspace code 唯一；创建者+幂等键唯一；角色 workspace+code 唯一；角色/权限关联唯一；workspace+member 唯一。成员的复合外键要求 `workspaceId` 和 `roleId` 指向同一 Workspace 下的角色。所有硬删除引用使用 `RESTRICT`；本卡不实现删除或状态服务。

以 Prisma 6.19.0 从卡开始 Schema 快照生成单一新增迁移 `20261029030000_client_workspace`。没有迁移或导入邀请、角色历史、企业资料、IP、诊断、订单、权益、业务 Prompt、Workspace 客户行或旧表记录。无 controller、service、DTO、guard、API、页面、菜单、权限授予或默认租户 Seed；这些不属于 G10-01。

任务校验支持文件将 AF-053 加入本库随机验收库 allowlist；迁移操作证据按验收任务号写入 `.artifacts/af-053/operations/`，避免误记到 AF-010 目录。旧客户身份类型 fixture 更新为断言客户 Workspace 关系可用、管理员 `userRoles` 仍不可从客户身份写入。

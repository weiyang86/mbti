## 当前实现（验证前）

- 新增 `GET /api/client/files?page=&pageSize=`：只列出当前 project、当前客户 owner、无 Workspace/plugin 的文件；固定稳定排序和分页，响应不含本地路径、对象键或校验值。
- 新增 `GET /api/admin/files?page=&pageSize=` 与 `GET /api/admin/files/:id`：显式 `admin.file.read` 权限；仅列出当前项目通用客户文件，不含路径/对象键/校验值；管理员下载仍按数据库项目 scope 查找。
- 后台新增 `/auth/files` 页面，菜单页面目录只登记真实页面路径；通过既有菜单 API 配置授权导航。客户前端产品页尚未实现，本卡提供客户真实 HTTP 列表/查看接口。
- 共享 `FileContentService` 验证存储字节长度和 SHA-256；缺失对象标为 `missing` 并拒绝下载，损坏内容标为 `corrupt` 并返回通用错误、不输出字节。无需 Schema 或 migration 修改。
- 新增显式 Seed 选项 `--files`，仅登记 `admin.file.read` 权限目录，不自动赋权、不自动创建菜单；AF-048 客户/管理员测试 fixture 只写入随机隔离验收库和忽略目录。

## 实现与影响

- `aij-payment` 通过 `POST /api/payments/callbacks/:projectCode/:providerCode` 接收回调；使用原始 HTTP body、时间戳、事件 ID、项目/Provider 上下文做 HMAC-SHA256 验证，复用 IntegrationCenter 已有的 timing-safe 原语，不复用其入站账本。
- 回调只接受严格 allowlist 字段。签名有效后，项目、Provider、订单、支付尝试、SecretRef、金额、币种和状态都由服务端核对。失败签名/过期/未知项目/畸形请求 fail-closed；已验签的状态冲突、金额/币种拒绝、重放及 SecretRef 轮换竞态都持久化拒绝收据和去敏审计。
- 新增 `PaymentCallbackEvent` 与 `PaymentTransaction`；交易事实仅在成功状态追加。迁移增加唯一键、金额/币种/摘要约束与 Restrict 外键；未修改历史 migration。PaymentAttempt 只保存 `credentialRef`，SecretCenter 负责解析，不存凭据明文。
- API 页面、RBAC 权限、外部 Provider、真实收款/退款均未新增/调用。synthetic Provider 只用于本库隔离验收，不证明真实支付接入。
- DB owner 为 `apps/api/src/plugins/aij-payment`；SecretCenter 仅解析 SecretRef；AuditLog 继续由原审计 owner 落库。

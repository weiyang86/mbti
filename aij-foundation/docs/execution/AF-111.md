## 本卡范围与评测规则

- 建立 20 个全合成评测问题：18 个有对应 Workspace 文档与确定答案标记的可回答样例；2 个不可回答样例，分别在一个 Workspace 内询问另一个 Workspace 专属知识。
- 使用真实 loopback HTTP 和随机隔离 PostgreSQL 创建合成 Workspace、文档、问题和 AsyncRuntime 工作；调用只允许由 `NODE_ENV=test`、`APP_ENV=test`、显式 offline Provider 模式开启的合成 Provider。
- 可回答通过条件：HTTP 问题最终为 `answered`，答案包含该样例预设的答案标记，服务端引用中包含唯一预期文档代码。回答得分为通过可回答样例数 / 18，阈值 ≥ 90%。
- 无依据拒答通过条件：2/2 结果均为 `refused / INSUFFICIENT_EVIDENCE` 且没有引用、RuntimeJob 或模型 Trace。跨 Workspace 隔离通过条件：两个拒答样例无外区内容或引用；登录成员读取另一 Workspace 问题返回 404，跨 Workspace 请求返回 403；20 条结果引用只能指向当前 Workspace 文档。
- 指标按实际 HTTP/数据库结果计算；不能以 provider fixture、打印的成功文本或静态代码扫描代替真实端到端校验。离线 Provider 通过不证明 DeepSeek live 接入。

## 1. 通用约定

### 1.1 Base URL

| 环境 | Base URL | 说明 |
|------|----------|------|
| 开发草稿 | `http://mbti-dev.101.43.150.46.sslip.io/api/v1` | **后端尚未上线**；当前前端默认走 mock |
| 前端配置 | `VITE_API_BASE_URL`（见 `web/.env.example`） | 未配置时默认 `/api/v1` |

所有路径下文均写完整形式：`METHOD /api/v1/...`。

### 1.2 鉴权

二选一（草案 stub）：

| 方式 | Header | 说明 |
|------|--------|------|
| 登录用户 | `Authorization: Bearer <access_token>` | stub access token |
| 游客联调 | `X-Guest-Token: <guest_token>` | 前端可用环境变量 `VITE_GUEST_TOKEN` |

微信登录（`code2session` 等）**TODO**，待 Remy 定稿。

`GET /api/v1/health` 无鉴权要求（草案）。

### 1.3 Content-Type

请求体（有 body 时）：`application/json; charset=utf-8`

### 1.4 统一错误格式（错误包络）

失败时 HTTP 非 2xx，响应 JSON：

```json
{
  "code": "string_machine_code",
  "message": "human readable",
  "details": {}
}
```

| HTTP | 典型 `code` | 白话说明 |
|------|-------------|----------|
| 400 | `invalid_request` | 参数写错了 / 校验失败 |
| 401 | `unauthorized` | 没带 token 或 token 无效 |
| 404 | `not_found` | 资源找不到 |
| 409 | `conflict` | 状态冲突（例如同一会话重复提交） |
| 422 | `unprocessable` | 语义上处理不了（例如对比的两份题库版本不同） |
| 500 | `internal_error` | 服务端内部错误 |

### 1.5 Mock 开关（前端）

| 环境变量 | 作用 |
|----------|------|
| `VITE_USE_MOCK=true` | 前端不打真实后端，走 `web/src/api/mock/` |
| `VITE_API_BASE_URL` | 真实请求前缀 |
| `VITE_GUEST_TOKEN` | 自动附加 `X-Guest-Token` |

**当前：** 后端尚未上线，联调请开 mock。下文 curl 仅作请求形状示例。

### 1.6 术语（首次出现白话）

| 术语 | 一句话 |
|------|--------|
| **幂等** | 同一操作做多次，效果与成功做一次相同；本草案里 `submit` 只允许成功一次，再提交会 `409` |
| **快照（ResultSnapshot）** | 提交测验或自选类型后生成的一份**不可变**结果记录；复测会新建快照，不覆盖旧的 |
| **question_bank_version** | 题库版本号；题库改了就递增；历史快照记住提交当时的版本；**对比两份结果时版本必须相同** |
| **source** | 结果来源：`quiz`=答题得出，`self_select`=用户自选类型 |
| **dimension / 维度** | MBTI 四维：`EI` / `SN` / `TF` / `JP`；产品规则 4 维 × 3 题 = 12 题 |

## 2. 接口总览（带教闭环顺序）

| 顺序 | 环节 | 方法 | 路径 | 一句话 |

## 4. 测（题库与会话）

### 4.1 获取当前题库与 12 道题

#### 接口

拉取当前生效的题库版本和固定 12 道选择题（4 维 × 3 题，无自由文本）。`GET /api/v1/quiz/versions/current`

#### 请求参数

| 参数名 | 位置 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|------|--------|
| Authorization | header | string | 否* | Bearer 鉴权；与游客头二选一 | `Bearer eyJhbGciOi...` |
| X-Guest-Token | header | string | 否* | 游客联调 token | `guest_dev_001` |

\* 草案全局默认需要鉴权之一；具体是否对读题库放宽 **待 Remy 定稿**。

无 path / query / body。

#### 返回示例

成功 `200`：

```json
{
  "question_bank_version": "qb-v0.4-teach-1",
  "lookback_hint": "请按最近四周的通常状态作答",
  "questions": [
    {
      "id": "q1",
      "index": 1,
      "dimension": "EI",
      "prompt": "最近四周，更常从独处中恢复精力？",
      "options": [
        { "id": "e", "label": "更贴近 E 侧（同意/是）" },
        { "id": "i", "label": "更贴近 I 侧（不同意/否）" }
      ]
    }
  ]
}
```

（完整响应含 12 题；上表仅示意第 1 题。示例值按草案 schema + 前端 mock 题库形状编写。）

| 字段 | 类型 | 说明 |
|------|------|------|
| `question_bank_version` | string | 当前题库版本号 |
| `lookback_hint` | string | 可选；UX 文案「请按最近四周…」，**不是**服务端校验字段 |
| `questions` | array | 恰好 12 道题 |
| `questions[].id` | string | 题目 id |
| `questions[].index` | integer | 题序 1–12 |
| `questions[].dimension` | string | `EI` \| `SN` \| `TF` \| `JP` |
| `questions[].prompt` | string | 题干 |
| `questions[].options` | array | 固定选项（至少 2 个） |
| `questions[].options[].id` | string | 选项 id（提交答案用） |
| `questions[].options[].label` | string | 选项文案 |

常见错误：

`401`：

```json
{
  "code": "unauthorized",
  "message": "missing or invalid token",
  "details": {}
}
```

可选 curl：

```bash
curl -s -H "X-Guest-Token: guest_dev_001" \
  http://mbti-dev.101.43.150.46.sslip.io/api/v1/quiz/versions/current
```

| question_bank_version | body | string | 否 | 可选锁定版本；省略则用当前题库 | `qb-v0.4-teach-1` |

### 4.3 写入 / 更新答案

#### 接口

在会话未提交前，批量或增量更新答案（可多次调用）。`PUT /api/v1/quiz/sessions/{session_id}/answers`

#### 请求参数

| 参数名 | 位置 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|------|--------|
| session_id | path | string | 是 | 会话 id | `sess_m3k2a1_ab12cd` |
| Authorization | header | string | 否* | Bearer | `Bearer eyJhbGciOi...` |
| X-Guest-Token | header | string | 否* | 游客 token | `guest_dev_001` |
| answers | body | array | 是 | 答案列表 | 见下 |
| answers[].question_id | body | string | 是 | 题目 id | `q1` |
| answers[].option_id | body | string | 是 | 选中的选项 id | `i` |

请求体示例：

```json
{
  "answers": [
    { "question_id": "q1", "option_id": "i" },
    { "question_id": "q2", "option_id": "i" },
    { "question_id": "q3", "option_id": "e" }
  ]
}
```

#### 返回示例

成功 `200`（返回更新后的会话）：

```json
{
  "id": "sess_m3k2a1_ab12cd",
  "question_bank_version": "qb-v0.4-teach-1",
  "status": "in_progress",
  "answers": [
    { "question_id": "q1", "option_id": "i" },
    { "question_id": "q2", "option_id": "i" },
    { "question_id": "q3", "option_id": "e" }
  ],
  "created_at": "2026-11-04T03:00:00.000Z",
  "updated_at": "2026-11-04T03:05:00.000Z"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| （同 QuizSession） | | 见 4.2；`answers` 为合并后的全集 |

常见错误：

`404`：

```json
{
  "code": "not_found",
  "message": "session not found",
  "details": {}
}
```

`400`：

```json
{
  "code": "invalid_request",
  "message": "answers is required",
  "details": {}
}
```

可选 curl：

```bash
curl -s -X PUT -H "Content-Type: application/json" -H "X-Guest-Token: guest_dev_001" \
  -d '{"answers":[{"question_id":"q1","option_id":"i"}]}' \
```

### 4.4 提交测验（生成结果快照）

#### 接口

提交本场测验一次，服务端计分并生成**不可变**结果快照（`source=quiz`）。**幂等约束：** 同一 `session_id` 只允许成功提交一次；重复 → `409`。`POST /api/v1/quiz/sessions/{session_id}/submit`

计分映射表（选项 → 维度计数 → 类型字母）**待 Remy 定稿**。

#### 请求参数

| 参数名 | 位置 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|------|--------|
| session_id | path | string | 是 | 会话 id | `sess_m3k2a1_ab12cd` |
| Authorization | header | string | 否* | Bearer | `Bearer eyJhbGciOi...` |
| X-Guest-Token | header | string | 否* | 游客 token | `guest_dev_001` |
| life_stage | body | string | 否 | 背景标签，仅存储，不参与计分 | `campus` |
| recent_status | body | string | 否 | 背景标签，仅存储，不参与计分 | `job_hunting` |

请求体示例（可 `{}` 或省略）：

```json
{
  "life_stage": "campus",
  "recent_status": "job_hunting"
}
```

#### 返回示例

成功 `201`：

```json
{
  "id": "res_m3k2b9_xy98zz",
  "source": "quiz",
  "type_code": "INFP",
  "dimension_counts": {
    "E": 1,
    "I": 2,
    "S": 1,
    "N": 2,
    "T": 0,
    "F": 3,
    "J": 1,
    "P": 2
  },
  "question_bank_version": "qb-v0.4-teach-1",
  "submitted_at": "2026-11-04T03:10:00.000Z",
  "life_stage": "campus",
  "recent_status": "job_hunting",
  "session_id": "sess_m3k2a1_ab12cd"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | string | 结果快照 id |
| `source` | string | 固定为 `quiz` |
| `type_code` | string | 四字母类型，如 `INFP`（模式 `^[EI][SN][TF][JP]$`） |
| `dimension_counts` | object | 八向计数；每维两侧合计应与该维题数相关（草案每侧 0–3） |
| `question_bank_version` | string | 提交时绑定的题库版本 |
| `submitted_at` | string | 提交时间 ISO |
| `life_stage` | string | 可选背景 |
| `recent_status` | string | 可选背景 |
| `session_id` | string | 来源会话 id（`source=quiz` 时） |

常见错误：

`409`（已提交过）：

```json
{
  "code": "conflict",
  "message": "already submitted",
  "details": {}
}
```

`404`：

```json
{
  "code": "not_found",
  "message": "session not found",
  "details": {}
}
```

可选 curl：

```bash
curl -s -X POST -H "Content-Type: application/json" -H "X-Guest-Token: guest_dev_001" \
  -d '{"life_stage":"campus"}' \
  http://mbti-dev.101.43.150.46.sslip.io/api/v1/quiz/sessions/sess_m3k2a1_ab12cd/submit
```

### 5.3 自选类型创建快照

#### 请求参数

| 参数名 | 位置 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|------|--------|

| source | body | string | 是 | 必须为 `self_select` | `self_select` |
| life_stage | body | string | 否 | 背景标签 | `campus` |
| recent_status | body | string | 否 | 背景标签 | `stable` |

请求体示例：

## 6. 晒预览

### 6.1 请求分享预览

#### 接口

请求生成分享预览图（服务端可 stub）。响应可给同步 `preview_url` 和/或异步 `job_id`——二者是否同时返回 **待 Remy 定稿**。`POST /api/v1/share/preview`

**禁止**在预览 payload 中携带原始答题选项；客户端本地渲染时也不得绘制 raw answers。

#### 请求参数

| 参数名 | 位置 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|------|--------|
| Authorization | header | string | 否* | Bearer | `Bearer eyJhbGciOi...` |
| X-Guest-Token | header | string | 否* | 游客 token | `guest_dev_001` |
| result_id | body | string | 是 | 要晒的结果快照 id | `res_m3k2b9_xy98zz` |
| template_id | body | string | 否 | 视觉模板 key | `default_card` |
| scene | body | string | 否 | 场景：`moments` \| `avatar` \| `meet_card` | `moments` |

请求体示例：

```json
{
  "result_id": "res_m3k2b9_xy98zz",
  "template_id": "default_card",
  "scene": "moments"
}
```

#### 返回示例

成功 `200`（同步就绪示意）：

```json
{
  "preview_url": "https://cdn.example.com/share/res_m3k2b9_xy98zz.png",
  "status": "ready"
}
```

异步 pending 示意（字段组合 **待 Remy 定稿**）：

```json
{
  "job_id": "job_share_001",
  "status": "pending"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `preview_url` | string (uri) | 可选；可直接展示的预览地址 |
| `job_id` | string | 可选；异步任务 id（轮询 endpoint **待 Remy 定稿**） |
| `status` | string | `ready` \| `pending` |

常见错误：

`404`：

```json
{
  "code": "not_found",
  "message": "result not found",
  "details": {}
}
```

`400`：

```json
{
  "code": "invalid_request",
  "message": "result_id is required",
  "details": {}
}
```

可选 curl：

```bash
curl -s -X POST -H "Content-Type: application/json" -H "X-Guest-Token: guest_dev_001" \
  -d '{"result_id":"res_m3k2b9_xy98zz","scene":"moments"}' \
  http://mbti-dev.101.43.150.46.sslip.io/api/v1/share/preview
```

## 7. 阶段记录

### 7.1 列出我的结果快照

#### 接口

列出当前用户的历史快照（**默认私有**）。按 `submitted_at` 降序；列表层为摘要，不含原始答案明细。`GET /api/v1/results`

分页：草案提供 `limit` + `cursor`；cursor vs offset 细节 **待 Remy 定稿**。

#### 请求参数

| 参数名 | 位置 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|------|--------|
| limit | query | integer | 否 | 1–100，默认 20 | `20` |
| cursor | query | string | 否 | 分页游标 | `eyJpZCI6InJlcy...` |
| Authorization | header | string | 否* | Bearer | `Bearer eyJhbGciOi...` |
| X-Guest-Token | header | string | 否* | 游客 token | `guest_dev_001` |

#### 返回示例

成功 `200`：

```json
{
  "items": [
    {
      "id": "res_m3k2b9_xy98zz",
      "source": "quiz",
      "type_code": "INFP",
      "question_bank_version": "qb-v0.4-teach-1",
      "submitted_at": "2026-11-04T03:10:00.000Z",
      "life_stage": "campus"
    }
  ],
  "next_cursor": null
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `items` | array | 摘要列表 |
| `items[].id` | string | 快照 id |
| `items[].source` | string | `quiz` \| `self_select` |
| `items[].type_code` | string | 类型字母 |
| `items[].question_bank_version` | string | 提交时题库版本 |
| `items[].submitted_at` | string | 提交时间 |
| `items[].life_stage` | string | 可选 |
| `next_cursor` | string \| null | 下一页游标；无更多则为 null |

常见错误：

`401`：

```json
{
  "code": "unauthorized",
  "message": "missing or invalid token",
  "details": {}
}
```

可选 curl：

```bash
curl -s -H "X-Guest-Token: guest_dev_001" \
  "http://mbti-dev.101.43.150.46.sslip.io/api/v1/results?limit=20"
```

### 7.2 对比两次快照

#### 接口

对比两份快照的类型变化与四维计数差。**约束：** 两边的 `question_bank_version` **必须相同**，否则 `422`。`GET /api/v1/results/compare`

#### 请求参数

| 参数名 | 位置 | 类型 | 必填 | 说明 | 示例值 |
|--------|------|------|------|------|--------|
| baseline_id | query | string | 是 | 基线快照 id | `res_old_001` |
| target_id | query | string | 是 | 对比目标快照 id | `res_m3k2b9_xy98zz` |
| Authorization | header | string | 否* | Bearer | `Bearer eyJhbGciOi...` |
| X-Guest-Token | header | string | 否* | 游客 token | `guest_dev_001` |

#### 返回示例

成功 `200`：

```json
{
  "baseline_id": "res_old_001",
  "target_id": "res_m3k2b9_xy98zz",
  "question_bank_version": "qb-v0.4-teach-1",
  "type_changed": true,
  "baseline_type_code": "ISFP",
  "target_type_code": "INFP",
  "dimension_deltas": {
    "E": 0, "I": 0, "S": -1, "N": 1, "T": 0, "F": 0, "J": 0, "P": 0
  },
  "stability_notes": []
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `baseline_id` | string | 基线 id |
| `target_id` | string | 目标 id |
| `question_bank_version` | string | 两边相同的版本 |
| `type_changed` | boolean | 类型字母是否变化 |
| `baseline_type_code` | string | 基线类型 |
| `target_type_code` | string | 目标类型 |
| `dimension_deltas` | object | 可选；各字母计数差（target − baseline） |
| `stability_notes` | string[] | 可选；如类型未变时的提示文案 |

常见错误：

`422`（版本不一致）：

```json
{
  "code": "unprocessable",
  "message": "question_bank_version mismatch",
  "details": {}
}
```

`404`：

```json
{
  "code": "not_found",
  "message": "snapshot not found",
  "details": {}
}
```

可选 curl：

```bash
curl -s -H "X-Guest-Token: guest_dev_001" \
  "http://mbti-dev.101.43.150.46.sslip.io/api/v1/results/compare?baseline_id=res_old_001&target_id=res_m3k2b9_xy98zz"
```

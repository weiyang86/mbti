## 4. curl 闭环（与带教顺序一致）

以下与 P0 smoke 一致；除 `health` 外均需 `X-Guest-Token`。

```bash
BASE="https://mbti-dev.bestshizhongyu.com"
GUEST="guest_dev_001"
AUTH=(-H "X-Guest-Token: ${GUEST}" -H "Content-Type: application/json" -H "Accept: application/json")

# 0 探活
curl -sS "${BASE}/api/v1/health"

# 1 题库
curl -sS "${AUTH[@]}" "${BASE}/api/v1/quiz/versions/current"

# 2 开会话
SESS=$(curl -sS -X POST "${AUTH[@]}" -d '{}' "${BASE}/api/v1/quiz/sessions")
SID=$(echo "$SESS" | sed -n 's/.*"id":"\([^"]*\)".*/\1/p' | head -1)

# 3 写 12 题答案（option_id 与 stub 题库一致，见接口文档）
curl -sS -X PUT "${AUTH[@]}" -d '{"answers":[
  {"question_id":"q1","option_id":"i"},{"question_id":"q2","option_id":"n"},
  {"question_id":"q3","option_id":"f"},{"question_id":"q4","option_id":"p"},
  {"question_id":"q5","option_id":"i"},{"question_id":"q6","option_id":"n"},
  {"question_id":"q7","option_id":"f"},{"question_id":"q8","option_id":"p"},
  {"question_id":"q9","option_id":"i"},{"question_id":"q10","option_id":"n"},
  {"question_id":"q11","option_id":"f"},{"question_id":"q12","option_id":"p"}
]}' "${BASE}/api/v1/quiz/sessions/${SID}/answers"

# 4 提交 → 拿 result id
RES=$(curl -sS -X POST "${AUTH[@]}" -d '{"life_stage":"campus"}' \
  "${BASE}/api/v1/quiz/sessions/${SID}/submit")
RID=$(echo "$RES" | sed -n 's/.*"id":"\([^"]*\)".*/\1/p' | head -1)

# 5 查结果
curl -sS "${AUTH[@]}" "${BASE}/api/v1/results/${RID}"

# 6 16 型元数据
curl -sS "${AUTH[@]}" "${BASE}/api/v1/types"

# 7 自选快照
curl -sS -X POST "${AUTH[@]}" -d '{"type_code":"INFP","source":"self_select"}' \
  "${BASE}/api/v1/results"

# 8 分享预览 stub
curl -sS -X POST "${AUTH[@]}" -d "{\"result_id\":\"${RID}\",\"scene\":\"moments\"}" \
  "${BASE}/api/v1/share/preview"

# 9 历史列表
curl -sS "${AUTH[@]}" "${BASE}/api/v1/results?limit=20"
```

完整自动化脚本逻辑见运维侧 `mbti-api-stub/smoke.sh`（仓库外）；上表足够手工验证。

**幂等：** 同一会话第二次 `submit` 应 **409** `conflict`。

**无 Token：** 例如 `GET /api/v1/types` 不带头 → **401** `unauthorized`（正常）。

## 5. 常见失败与排查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| `502` / HTML 错误页 | nginx 未反代或 stub 进程未起 | 仅运维处理；实习生记录时间、URL、响应片段到联调笔记 |
| `401 unauthorized` | 未带 `X-Guest-Token` / Bearer | 检查 `VITE_GUEST_TOKEN` 与请求拦截器 |
| `404 session not found` | 用了旧 `session_id`（stub 重启后） | 重新 `POST /quiz/sessions` |
| `409 already submitted` | 重复提交同一会话 | 前端应禁用二次提交；联调时换新 session |
| `422 question_bank_version mismatch` | 对比两次快照版本不同 | 仅对比相同 `question_bank_version` 的两条 quiz 结果 |
| CORS / 网络错误 | 旧域名、本地 http 混用 | 统一 `bestshizhongyu` + HTTPS Base |
| 数据「消失」 | stub 重启 | **预期**；勿当持久化 DB |
| `/admin/` 502 | 后台未部署 | **预期**；与 H5 P0 无关 |

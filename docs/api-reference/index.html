先确认这几条边界

身份与公开范围

结果和订单只属于本人。名片默认私密；公开字段按可见性返回，任意方向屏蔽都会收紧访问。

联系方式

名片交换不会自动授予渠道。只有原申请人能读取明确批准的集合；撤回、清除、换值等会使旧授权失效。

支付与人数

订单用于受控测试，真实支付通道未配置。雷达只保存参与选择，人数明确不可用，不代表 0 人或低样本。

通用响应处理

成功直接返回业务对象；204 没有响应体。错误格式为 {code,message}，部分原始候选允许可选 details，以该接口 Schema 为准。

状态码联调时的处理
401缺少、失效或非法游客凭证。明确处理失效，不自动换号重试。
404对象不存在、不属于本人、当前不可见或授权无效；不回填旧私密缓存。
409已提交、幂等冲突或角色/状态冲突。先重读服务端状态，再决定下一次操作。
422字段、格式或业务前置条件不满足。核对具体错误码和契约。
500 / 503请求失败，保留明确错误；不会自动变成成功、人数较少或统计不可用。

运营同号查单

运营使用现有 Foundation 登录与 mbti:orders:read 权限，请求 /api/admin/mbti/orders/{id}。它的前缀是 /api，不属于游客的 /api/v1 接口目录；运营凭证不放入前端或本文档。

契约来源与版本

生成时对 Schema、响应和鉴权方案做名称隔离，将 OpenAPI 3.0 的 nullable 等表达转换为 3.1；候选字段、操作和原始文件保持不变。原始候选中的历史说明以对应批次验收记录为准。

真实人数仍缺自愿位置来源、位置授权、距离算法、半径口径和经确认的小样本政策。正式价格、履约、留存及物理擦除策略仍待业务审核。

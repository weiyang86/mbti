## 调用接口

依据 `docs/api/接口文档-实习生版.md` 6.1：

| 时机 | 接口 | 前端封装 | 参数 |
|---|---|---|---|
| 进入页面 | `GET /api/v1/results/{id}` | `getResult()` | 读 `type_code`、`source` |
| 进入页面 | `GET /api/v1/types` | `listTypes()` | 中文名 / tagline |
| 进入 & 切场景 | `POST /api/v1/share/preview` | `createSharePreview()` | `{ result_id, scene }` |

`scene` 取值严格按文档：`moments` / `avatar` / `meet_card`，对应页面三个 tab。

## 结论

按原型 `scenePreview()` / `sceneTabs()` 还原三个场景：

1. **发朋友圈**：朋友圈头部（头像 + 匿名昵称 + 未发布标注）、配文、大图卡（类型 + 名称）、`AI 示例人物` 徽标
2. **换同款头像**：1:1 头像框 + 类型角标、标题与说明
3. **见面亮名片**：深色名片卡（`HELLO, I'M` + 类型 + 名称 + tagline），标注**不含联系方式**

风格切换：三套素材从原型 `ASSETS` 导出为 `web/src/static/share-style-{illustration,editorial,game}.webp`，仅影响预览图，不影响接口请求。

本地 mock 验证：三个场景与三个风格均可切换，图片正常显示，控制台无 error，`npm run build:h5` 通过。

## 卡点 / 需拍板

- **服务端预览图未直接展示**：mock 的 `preview_url` 指向 `/static/share-mock.png`，工程里没有该文件；本期用客户端本地渲染，服务端结果只用于状态显示。真后端接入后需确认 `preview_url` 是否可直接展示。
- **`job_id` 轮询未定义**：文档标注异步轮询 endpoint 待定稿，前端未实现轮询，只用同步 `status`。
- **风格与 `template_id` 的关系未定**：原型三套风格是本地素材，接口只有可选 `template_id`，需 Remy 明确风格是否要服务端下发模板。
- **头像「可单独下载」未实现**：需要下载/导出能力，契约里没有对应接口，本期只做预览。
- 原型 `offer()` 里的价值套装网格与 ¥9.9 入口属支付范围（OUT OF SCOPE），未实现。

## 调用接口

依据 `docs/api/接口文档-实习生版.md` 7.1 / 7.2 / 7.3：

| 用途 | 接口 | 前端封装 | 说明 |
|---|---|---|---|
| 读快照详情 | `GET /api/v1/results/{id}` | `getResult()` | `type_code` / `source` / `submitted_at` / `question_bank_version` / `dimension_counts` |
| 找同版本上一条 | `GET /api/v1/results?limit=50` | `listResults()` | 前端筛出 `question_bank_version` 相同且更早的一条 |

- [x] 页面不展示原始答题选项（原型 `recordPage` 里的"回看 12 个选择"未实现）
- [x] 删除前二次确认，删除后回列表
- [ ] `422 / 404` 的友好提示待真后端联调验证

## 结论

按原型 `recordPage` 还原：页头（类型 · 中文名 · 时间 · 来源）、私有提示卡（🔒 阶段信息仅自己可见）、四维分布、同版本对比区、晒图预览与删除入口。

对比交互：先给「与上一次同版本记录比较」按钮，点击后调 `compareResults` 渲染结果，不自动请求（避免误触发）。

本地 mock 验证：INFP 记录详情 → 点对比 → 显示「类型未变（INFP）」与提示文案，控制台无 error。

## 卡点 / 需拍板

- **原型展示原始选择，本期不做**：`recordPage` 有「回看当时的 12 个选择」，但 `resources.md` 标明详情是否返回 option 级明细**待 Remy 定稿**，且隐私口径偏保守，故不实现。
- **删除是软删还是硬删未定**（`resources.md` 标注待定稿）；删除后已生成分享图的引用如何处理也未定。
- **`life_stage` / `recent_status` 没有写入入口**：详情页留了展示位，但答题页本期未采集，需要 Remy 明确是否要采集。
- **同版本上一条的选择逻辑在前端**：文档没有「取上一条」接口，只能用列表过滤；若记录很多（超过 50 条）可能选不到，需 Remy 确认是否要服务端提供「上一条同版本」。

# 06 · 阶段记录 · 列表 · 联调笔记

- 日期：2026-11-04

## 调用接口

依据 `docs/api/接口文档-实习生版.md` 7.1：

| 用途 | 接口 | 前端封装 | 参数 |
|---|---|---|---|
| 读我的快照列表 | `GET /api/v1/results` | `listResults()` | `limit=50` |
| 类型中文名 | `GET /api/v1/types` | `listTypes()` | `items[].name_zh` |

## 字段核对

- [x] 列表按 `submitted_at` 降序（后端保证，前端不再排序）
- [x] 只渲染摘要字段：`id` / `source` / `type_code` / `submitted_at` / `question_bank_version`
- [x] `source` 只按 `quiz` / `self_select` 切换标签配色与文案
- [x] 列表不展示任何答题明细
- [ ] `next_cursor` 分页未消费（本期 50 条足够）
- [ ] 鉴权头（`X-Guest-Token`）待真后端验证

## 结论

按原型 `record-timeline` / `record-tile` 还原：左侧竖线 + 编号节点 + 记录卡（类型、中文名、来源标签、时间、题库版本），点击进入详情。

空状态给出「还没有阶段记录 → 去测一测」；列表底部提供「再测一次」。

本地 mock 验证：列表中同时出现 `self_select` 与 `quiz` 两种来源的记录卡，编号与时间正常，控制台无 error。

## 卡点 / 需拍板

- **分页未做**：文档 `limit` + `cursor` 仍属草案（cursor vs offset 待定稿），本期只取前 50 条。
- **tabBar 合入后会变成 tab 页**：首页分支把 `pages/history/list` 配置为「我的轨迹」tab。页面跳转已统一用 `uni.reLaunch`，两种形态都可运行，但需 Remy 在合并后确认导航体验。
- 原型列表顶部还有「阶段变化图表」（`journey-chart`），本期未做——需要跨记录计算趋势，现有接口只提供单条计数，需额外契约支持。

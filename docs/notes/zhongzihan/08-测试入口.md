## 卡点 / 需拍板

- **昵称/兴趣没有契约字段**：按你的要求先采集并本机保存，但**没有硬塞进接口 body**（避免擅自设计业务字段）。需要 Remy 在契约里补 `name` / `interests`，或确认「仅前端展示」。
- `life_stage` / `recent_status` 文档允许任意字符串（示例是 `campus`），本期直接提交中文标签（如「日常生活」），需 Remy 确认取值规范。
- 兴趣上限 3 项、阶段标签校验规则在契约里没有，属于前端 UX 约束。
- 演示条是原型自带的 Mock 标识，正式上线前需去掉或改成真实状态。

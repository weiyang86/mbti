## 结论

按原型 `typePicker()` 的 16 型网格还原，分组沿用原型顺序：分析家 / 外交家 / 守护者 / 探索者。

标题区按原型 `testIntro(true)` 的「MY TYPE / 直接做名片 → 把四个字母，做成你的专属形象。」实现；选中态高亮，底部 CTA 文案随选中类型变化（`用 INFP 看结果`）。

本地 mock 验证：4 组 16 张卡片正常；选 ISTJ 后 CTA 变为「用 ISTJ 看结果」；点击进入结果页并显示 ISTJ、来源 `self_select`，控制台无 error。

## 卡点 / 需拍板

- **交互形态与原型不同**：原型里"选类型"是首页表单里的**弹层**（`typePicker` modal），工程 `pages.json` 已把自选类型做成**独立页**。本期保留独立页、只搬网格视觉，需要 Remy 确认是否接受这种拆分。
- **去重未定**：文档标注"是否对重复自选去重"待定稿，前端按草案倾向每次新建快照，不做去重。
- **自选快照的 `question_bank_version`** 可能用哨兵值（如 `n/a-self-select`），文档未定稿；页面只展示接口返回值，不自行拼接。
- 原型里选完类型还会回到表单继续填昵称/兴趣，本期直接生成结果快照，跳过了这些字段（契约无昵称/兴趣字段）。
